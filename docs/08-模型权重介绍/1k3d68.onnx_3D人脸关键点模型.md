# 1k3d68.onnx - 3D 人脸关键点检测模型

## 基本信息

| 属性 | 值 |
|------|-----|
| 文件名 | `1k3d68.onnx` |
| 文件路径 | `backend/models/buffalo_l/1k3d68.onnx` |
| 文件大小 | 136.95 MB |
| ONNX 版本 | Opset 12 |
| 节点数量 | 178 |
| 模型类型 | 3D 人脸关键点检测 |
| 所属套件 | InsightFace Buffalo L |

## 模型用途

**功能**：检测 68 个 3D 人脸关键点

用于 3D 人脸对齐、人脸重建、表情分析等高级人脸分析任务。可配合其他人脸分析模型使用。

**检测内容**：
- 68 个 3D 坐标点（x, y, z）
- 覆盖面部轮廓、眼睛、鼻子、嘴巴等区域

## 技术细节

### 关键点分布

68 个关键点标准分布（遵循 iBUG 300-W 规范）：

```
0-16: 面部轮廓（17 点）
17-21: 左眉（5 点）
22-26: 右眉（5 点）
27-30: 鼻梁（4 点）
31-35: 鼻尖（5 点）
36-41: 左眼（6 点）
42-47: 右眼（6 点）
48-59: 外唇（12 点）
60-67: 内唇（8 点）
```
