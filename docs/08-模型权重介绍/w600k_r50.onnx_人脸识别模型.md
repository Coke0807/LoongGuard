## 模型用途

**功能**：人脸特征提取（人脸识别/比对）

提取人脸的 512 维特征向量，用于人脸比对和识别。

**应用场景**：
- 人脸验证（1:1 比对）
- 人脸搜索（1:N 识别）
- 人脸聚类

## 输入输出格式

### 输入

| 输入名称 | 形状 | 数据类型 | 说明 |
|----------|------|----------|------|
| `input.1` | (1, 3, 112, 112) | float32 | 对齐后的人脸图像 |

### 输出

| 输出名称 | 形状 | 说明 |
|----------|------|------|
| `683` | (1, 512) | 512 维人脸特征向量 |

特征向量特性：
- L2 归一化
- 余弦相似度用于比对
- 同一人脸相似度 > 0.4，不同人脸相似度 < 0.4

## 技术细节

### 人脸比对流程

```python
# 1. 提取特征向量
feature1 = model.predict(face_image1)  # (512,)
feature2 = model.predict(face_image2)  # (512,)

# 2. 计算余弦相似度
similarity = np.dot(feature1, feature2)

# 3. 判断是否同一人
is_same = similarity > 0.4
```

### 预处理

- 输入图像需先对齐（使用人脸检测 + 关键点对齐）
- 归一化到 [0, 1] 范围
- 缩放至 112×112
- BGR → RGB 转换（可选）
