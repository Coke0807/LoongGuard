# genderage.onnx - 性别年龄识别模型

## 基本信息

| 属性 | 值 |
|------|-----|
| 文件名 | `genderage.onnx` |
| 文件路径 | `backend/models/buffalo_l/genderage.onnx` |
| 文件大小 | 1.26 MB |
| ONNX 版本 | Opset 12 |
| 节点数量 | 102 |
| 模型类型 | 性别年龄分类 |
| 所属套件 | InsightFace Buffalo L |

## 模型用途

**功能**：人脸性别和年龄分类

对检测到的人脸进行性别和年龄估计，用于用户画像分析。

**输出内容**：
- 性别分类（男性/女性）
- 年龄估计（连续值或分段）

## 输入输出格式

### 输入

| 输入名称 | 形状 | 数据类型 | 说明 |
|----------|------|----------|------|
| `data` | (1, 3, 96, 96) | float32 | 对齐后的人脸图像 |

### 输出

| 输出名称 | 形状 | 说明 |
|----------|------|------|
| `fc1` | (1, 3) | 性别和年龄预测 |

输出格式说明：
- 索引 0：性别概率（0=女性，1=男性）
- 索引 1-2：年龄分布或年龄值

## 技术细节

### 预处理

- 输入图像需先对齐（使用人脸检测 + 关键点对齐）
- 归一化到 [0, 1] 范围
- 缩放至 96×96
