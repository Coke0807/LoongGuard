# yolo26_nano_int8.onnx - INT8 量化版 YOLO26 模型

## 基本信息

| 属性 | 值 |
|------|-----|
| 文件名 | `yolo26_nano_int8.onnx` |
| 文件路径 | `backend/models/yolo26_nano_int8.onnx` |
| 文件大小 | 9.49 MB |
| ONNX 版本 | Opset 13 |
| 节点数量 | 668 |
| 模型类型 | YOLO26-Nano 目标检测（INT8 量化） |
| 量化状态 | INT8 量化 |

## 模型用途

**功能**：危险物品检测（INT8 量化版本）

与 `best.onnx` 功能相同，但经过 INT8 量化优化，体积更小、推理更快。

**检测类别**：
- `scissor` - 剪刀
- `utility_knife` - 美工刀

## 与 best.onnx 的对比

| 对比项 | best.onnx | yolo26_nano_int8.onnx |
|--------|-----------|----------------------|
| 文件大小 | 9.80 MB | 9.49 MB |
| 量化状态 | FP32 | INT8 |
| 推理速度 | 较慢 | 更快 |
| 精度 | 更高 | 略低 |
| 内存占用 | 更多 | 更少 |

## 在项目中的应用

**当前状态**：可用，但默认配置使用 best.onnx（FP32）

**启用方式**：
```json
{
  "detection": {
    "model_path": "models/yolo26_nano_int8.onnx",
    "quantized": true
  }
}
```

或通过环境变量：
```bash
LG_DETECTION_QUANTIZED=true
```

## 性能对比

| 指标 | best.onnx (FP32) | yolo26_nano_int8.onnx (INT8) |
|------|------------------|------------------------------|
| 推理延迟 (x86) | ~30-50ms | ~20-35ms |
| 推理延迟 (LoongArch) | ~60-100ms | ~40-70ms |
| 内存占用 | ~100MB | ~80MB |
| 精度 (mAP) | 更高 | 略低（量化损失） |

## 注意事项

1. **精度损失**：INT8 量化会引入轻微精度损失
2. **预处理差异**：量化模型可能需要不同的归一化参数
3. **兼容性**：确保 ONNX Runtime 版本支持 INT8 量化模型
4. **默认配置**：项目默认使用 FP32 版本，需手动切换

## 适用场景

- 对实时性要求高、对精度要求稍低的场景
- 资源受限的边缘设备（如 LoongArch 2K3000）
- 需要更高吞吐量的部署环境

## 模型来源

从 best.onnx 进行 INT8 量化训练或后训练量化（PTQ）得到。
