# w600k_mbf.onnx - 早期人脸识别模型

## 基本信息

| 属性 | 值 |
|------|-----|
| 文件名 | `w600k_mbf.onnx` |
| 文件路径 | `backend/models/w600k_mbf.onnx` |
| 文件大小 | 12.99 MB |
| ONNX 版本 | Opset 11 |
| 节点数量 | 98 |
| 模型类型 | 人脸识别/特征提取（MobileFaceNet） |
| 网络架构 | MobileFaceNet |

## 模型用途

**功能**：人脸特征提取（早期版本）

与 `buffalo_l/w600k_r50.onnx` 功能类似，但使用更轻量的 MobileFaceNet 架构。

**当前状态**：已被 `w600k_r50.onnx` 替代，保留用于兼容性

## 与 w600k_r50.onnx 的对比

| 对比项 | w600k_mbf.onnx | w600k_r50.onnx |
|--------|----------------|----------------|
| 文件大小 | 12.99 MB | 166.31 MB |
| 节点数量 | 98 | 130 |
| 网络架构 | MobileFaceNet | ResNet-50 |
| 特征维度 | 512 | 512 |
| 推理速度 | 更快 | 较慢 |
| 精度 | 较低 | 更高 |

## 输入输出格式

### 输入

| 输入名称 | 形状 | 数据类型 | 说明 |
|----------|------|----------|------|
| `input.1` | (1, 3, 112, 112) | float32 | 对齐后的人脸图像 |

### 输出

| 输出名称 | 形状 | 说明 |
|----------|------|------|
| `516` | (1, 512) | 512 维人脸特征向量 |
