# 2d106det.onnx - 2D 人脸关键点检测模型

## 基本信息

| 属性 | 值 |
|------|-----|
| 文件名 | `2d106det.onnx` |
| 文件路径 | `backend/models/buffalo_l/2d106det.onnx` |
| 文件大小 | 4.80 MB |
| ONNX 版本 | Opset 12 |
| 节点数量 | 89 |
| 模型类型 | 2D 人脸关键点检测 |
| 所属套件 | InsightFace Buffalo L |

## 模型用途

**功能**：检测 106 个 2D 人脸关键点

用于精细的人脸对齐，比标准 68 点更密集，提高人脸对齐精度。

**检测内容**：
- 106 个 2D 坐标点（x, y）
- 更精细的面部区域覆盖

## 输入输出格式

### 输入

| 输入名称 | 形状 | 数据类型 | 说明 |
|----------|------|----------|------|
| `data` | (1, 3, 192, 192) | float32 | 对齐后的人脸图像 |

### 输出

| 输出名称 | 形状 | 说明 |
|----------|------|------|
| `fc1` | (1, 212) | 106 个关键点的 2D 坐标 (106 × 2 = 212) |

## 技术细节

### 106 点分布

106 点分布比标准 68 点更密集，包含：
- 更多的面部轮廓点
- 更精细的眼睛和嘴巴区域
- 额外的鼻部细节
