# det_500m.onnx - 早期人脸检测模型

## 基本信息

| 属性 | 值 |
|------|-----|
| 文件名 | `det_500m.onnx` |
| 文件路径 | `backend/models/det_500m.onnx` |
| 文件大小 | 2.41 MB |
| ONNX 版本 | Opset 11 |
| 节点数量 | 146 |
| 模型类型 | 人脸检测（RetinaFace 轻量版） |
| 量化状态 | 未量化 |

## 模型用途

**功能**：人脸检测（早期版本）

与 `buffalo_l/det_10g.onnx` 功能类似，但为更早期的轻量版本。

**当前状态**：已被 `det_10g.onnx` 替代，保留用于兼容性

## 与 det_10g.onnx 的对比

| 对比项 | det_500m.onnx | det_10g.onnx |
|--------|---------------|--------------|
| 文件大小 | 2.41 MB | 16.14 MB |
| 节点数量 | 146 | 158 |
| 模型架构 | RetinaFace 轻量版 | RetinaFace 标准版 |
| 检测精度 | 较低 | 更高 |
| 推理速度 | 更快 | 较慢 |

## 输入输出格式

### 输入

| 输入名称 | 形状 | 数据类型 | 说明 |
|----------|------|----------|------|
| `input.1` | (1, 3, 640, 640) | float32 | RGB 图像 |

### 输出

输出结构与 det_10g.onnx 相同，3 级 FPN 输出。

## 在项目中的应用

## 适用场景

- 资源受限的设备
- 对精度要求不高的场景
