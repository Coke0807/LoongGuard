# 系统设置

> 系统设置模块的功能清单及开发要求。以下为需要保存到 SQLite 数据库，并根据 `main.py` 风格开发的系统设置页面功能。

## 功能列表

| 功能 | 描述 |
| --- | --- |
| 自定义语音唤醒词 | 支持用户自定义唤醒词，可设置 1-3 个唤醒词，适配不同园所命名习惯 |
| 告警策略配置 | 每种告警类型可独立配置：是否启用、告警级别、是否发声、是否推送、是否录制，不同模式不同策略 |
| 视频录制配置 | 全局录制开关、录制分辨率、保存周期、存储位置、是否开启告警预录等参数配置 |
| 用户权限管理（扩展） | 多角色用户体系：超级管理员、园长、班主任、保健医、家长，不同角色不同功能权限 |
| 系统在线升级 | 支持OTA远程升级，升级包校验，升级失败自动回滚，升级过程不影响核心安全功能 |
| 时间与校时 | NTP网络自动校时，支持手动设置时间，时间同步状态显示，保障日志与告警时间准确 |
| 卡通主题切换（扩展） | 支持多套卡通UI主题：森林小动物、太空宇航员、海底世界等，适配不同幼儿园风格 |

## 开发要求

> 请将以上数据保存到 SQLite 数据库，并根据 `main.py` 风格，开发系统设置页面；当点击「系统设置」时，打开该页面。
