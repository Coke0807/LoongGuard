# 基于 LoongArch 的幼儿园 AI 安全卫士功能列表

> 整理自原 `基于LoongArch的幼儿园AI安全卫士功能列表.xls`（Sheet1），共 11 大模块、57 项功能。标注「（扩展）」的功能为规划中的扩展项。

## 1. 模式管理

| 子功能 | 描述 |
| --- | --- |
| 正常课堂模式 | 默认工作模式，启用危险物品识别、环境巡检、人数清点、温湿度监测等全量安全检测，告警级别正常 |
| 午睡模式 | 针对睡眠室场景优化：重点检测睡姿异常（趴睡、蒙头、手持物品入睡），降低普通告警灵敏度，声音音量降低提示 |
| 公共区域模式 | 适用于走廊、过道、操场等公共区域：重点检测地面水渍、杂物堆积、障碍物等隐患等环境巡检增强 |
| 模式切换 | 支持语音指令手动切换，切换时有语音确认反馈 |

## 2. 语音交互

| 子功能 | 描述 |
| --- | --- |
| 语音唤醒 | 支持自定义唤醒词（默认"小龙小龙"），远场拾音唤醒，唤醒后设备播放卡通提示音，进入待指令状态 |
| 语音交互 | 支持自然语言指令控制：模式切换、关闭告警、查询温湿度、开始录制、查看日志等简化指令 |
| 语音播报反馈 | 所有告警、状态变化、查询结果均通过语音播报输出，音量可调节，支持多种播报音色 |

## 3. AI 视觉安全检测

| 子功能 | 描述 |
| --- | --- |
| 危险物品识别 | 识别儿童手持危险物品：纽扣电池、曲别针、剪刀、尖锐物品、硬币、药片等，2秒内响应，红色警示框+强提醒音+管理端同步预警 |
| 睡姿异常检测 | 午睡时检测：趴睡、蒙头睡、被子捂住口鼻、手持危险物品入睡、床边坠落风险，静默告警不打扰睡眠 |
| 环境隐患自动巡检 | 全天候检测地面水渍、杂物堆积、障碍物等隐患，黄色框高亮标注，语音播报提示，自动记录时间位置形成台账 |
| 自动人数清点（扩展） | 自动统计教室内儿童数量，上下课清点对比，人数异常（少人/多人）时告警，配合考勤数据核对 |
| 儿童情绪识别（扩展） | 识别儿童哭闹、情绪低落、害怕等负面情绪，持续超过阈值提醒老师关注，辅助发现被欺凌或身体不适 |
| 肢体冲突检测（扩展） | 检测儿童间推搡、打架、霸凌等肢体冲突行为，实时告警，自动录制冲突全过程视频留证 |

## 4. 视频录制

| 子功能 | 描述 |
| --- | --- |
| 告警触发自动录制 | 安全告警事件触发时自动启动视频录制，事件前10秒预录+事件后30秒延续，完整留存事发过程 |
| 定时循环录制 | 支持全天定时录制，循环覆盖存储，可配置录制时段与画质，节省存储空间 |
| 视频回放与检索 | 按时间、告警类型、事件级别检索视频，支持快进、慢放、截图导出，时间轴可视化浏览 |
| 视频加密存储（扩展） | 所有视频文件加密存储，防止数据泄露，导出需授权，符合儿童隐私保护要求 |
| 录制参数配置 | 可独立开关视频录制功能，配置录制分辨率、保存周期、存储路径，存储空间不足自动清理策略 |

## 5. 环境监测

| 子功能 | 描述 |
| --- | --- |
| 温湿度实时监测 | 通过RS485温湿度传感器实时采集环境温湿度数据，屏幕卡通化显示，数据每秒刷新，历史曲线可查 |
| 温湿度阈值告警 | 温度过高/过低、湿度过高/干燥时自动告警，可自定义阈值，语音播报+弹窗提示，保障儿童舒适环境 |
| 空气质量扩展监测（扩展） | 支持外接PM2.5、CO2、甲醛传感器，监测教室空气质量，通风不良时提醒开窗换气 |
| 环境数据统计报表（扩展） | 按日/周/月生成环境质量报表，温湿度趋势曲线，超标次数统计，支持导出Excel |

## 6. 告警与联动

| 子功能 | 描述 |
| --- | --- |
| 三级告警分级 | 高危（红色）：危险物品；中危（黄色）：趴睡、蒙头睡、被子捂住口鼻、环境隐患、温湿度超标；低危（蓝色）：设备异常、提示类 |
| 现场声光告警 | 高危告警：红色弹窗+急促提示音；中危：黄色弹窗+温和提示音；午睡模式自动静音仅弹窗 |
| 管理端同步推送 | 所有告警实时推送到园方管理后台与老师移动端，包含告警截图、位置、时间，支持一键确认处理 |
| 告警确认闭环 | 告警需人工确认处理，记录处理人、处理时间、处理结果，未确认告警持续提醒，形成安全闭环 |
| 告警统计分析 | 按周/月统计告警数量、类型分布、处理时效，生成安全分析报告，识别高频风险点 |

## 7. 远程访问与家长端

| 子功能 | 描述 |
| --- | --- |
| 微信小程序远程查看 | 家长通过微信小程序授权后可实时观看孩子所在教室视频，支持语音对讲，低延迟流畅播放 |
| 家长授权管理 | 每个孩子绑定家长账号，仅可查看本班公共区域画面，观看权限可随时开关，支持临时授权 |
| 观看时段限制（扩展） | 家长观看仅限指定时段（如9:00-11:00，15:00-17:00），午睡、特殊活动时段自动关闭观看权限 |
| 告警消息推送（扩展） | 孩子相关的安全告警（如摔倒、情绪异常）推送给家长端，让家长及时了解孩子在园情况 |
| 成长瞬间推送（扩展） | 自动捕捉孩子活动、吃饭、游戏的精彩瞬间照片，定时推送给家长，增强家校连接 |
| 远程访问开关 | 总开关控制远程访问功能，关闭后所有外部访问禁用，数据完全本地运行，保障隐私安全 |

## 8. 设备自检与管理

| 子功能 | 描述 |
| --- | --- |
| 网络状态检测 | 开机自动检测网络连接状态，断网时本地离线运行不影响安全检测，网络恢复自动同步数据，断网时长记录 |
| 摄像头在线检测 | 实时检测摄像头连接状态，画面黑屏、遮挡、模糊时自动告警，记录故障时间，支持画面异常截图存证 |
| 麦克风状态检测 | 检测麦克风是否正常工作，拾音异常、静音、噪声过大时告警，保障语音交互与唤醒功能可用 |
| RS485温湿度传感器检测 | 自动检测RS485传感器连接状态，传感器离线、无应答、数据异常时提示设备不存在或离线，支持自动重连 |
| 扬声器状态检测 | 检测音频输出是否正常，播报失败、扬声器无声时记录故障，保障告警播报功能可用 |
| 存储容量检测 | 实时监测本地存储剩余空间，低于阈值时自动清理过期视频，存储满时告警提示，支持循环覆盖录制 |
| 开机全面自检 | 设备启动时自动执行全设备自检：CPU、内存、摄像头、麦克风、传感器、网络逐项检测，生成自检报告 |

## 9. 日志管理

| 子功能 | 描述 |
| --- | --- |
| 安全告警日志 | 详细记录每一条告警：时间、地点、类型、级别、截图、处理状态、处理人、处理结果，支持筛选导出 |
| 设备运行日志 | 记录设备开关机、模式切换、网络状态、传感器状态、故障异常等运行数据，用于运维排障 |
| 操作审计日志（扩展） | 记录所有管理员操作：配置修改、视频查看、数据导出、用户登录等，全程留痕可追溯 |
| 环境数据日志 | 温湿度、空气质量等环境数据按分钟级存储，支持历史查询与趋势导出 |
| 日志自动导出 | 支持按日/周自动导出各类日志报表，定时发送到管理邮箱，自动归档 |

## 10. 系统设置

| 子功能 | 描述 |
| --- | --- |
| 自定义语音唤醒词 | 支持用户自定义唤醒词，可设置1-3个唤醒词，适配不同园所命名习惯 |
| 告警策略配置 | 每种告警类型可独立配置：是否启用、告警级别、是否发声、是否推送、是否录制，不同模式不同策略 |
| 视频录制配置 | 全局录制开关、录制分辨率、保存周期、存储位置、是否开启告警预录等参数配置 |
| 用户权限管理（扩展） | 多角色用户体系：超级管理员、园长、班主任、保健医、家长，不同角色不同功能权限 |
| 系统在线升级 | 支持OTA远程升级，升级包校验，升级失败自动回滚，升级过程不影响核心安全功能 |
| 时间与校时 | NTP网络自动校时，支持手动设置时间，时间同步状态显示，保障日志与告警时间准确 |
| 卡通主题切换（扩展） | 支持多套卡通UI主题：森林小动物、太空宇航员、海底世界等，适配不同幼儿园风格 |

## 11. 数据统计

| 子功能 | 描述 |
| --- | --- |
| 安全事件统计 | 按时间段统计各类安全告警数量、级别分布、处理时效，生成趋势图与排行榜 |
| 设备运行统计 | 设备在线率、故障率、传感器可用率统计，多设备运行状态总览，异常设备高亮预警 |
| 环境质量日报 | 每日自动生成环境质量报告：平均温湿度、最高最低值、超标次数、空气质量等级 |
| 考勤统计报表（扩展） | 儿童每日出勤统计、出勤率、缺勤原因分析，按月生成考勤报表，对接财务收费 |
