# 视频流访问端口映射配置

> 配置 HTTPS 自签名证书、启用局域网远程访问，并通过 **SakuraFrp 内网穿透** 实现公网访问管理后台。

## 一、类型一：自签名证书【内网测试、无备案域名】

> ⚠️ **重大限制：自签证书微信小程序无法使用！**
> 小程序内核拒绝不受信任 CA，流媒体 HLS 直接加载失败。仅用于电脑浏览器调试。

### 生成自签名证书

```bash
sudo apt install openssl
# 创建证书目录
sudo mkdir -p /etc/ssl/local
cd /etc/ssl/local

# 一键生成（IP访问请后续配置SAN扩展，否则浏览器报名称不匹配）
sudo openssl req -x509 -nodes -days 3650 -newkey rsa:2048 \
-keyout server.key \
-out server.crt \
-subj "/C=CN/ST=Tianjin/L=Tianjin/O=Kindergarten/CN=192.168.3.13"
```

生成的证书文件：

- `server.crt` 证书（ssl_certificate）
- `server.key` 私钥（ssl_certificate_key）

**远程访问地址：**

```text
https://frp-bus.com:51594/admin/login
```

### 程序以 HTTPS 方式启动

```python
# 程序入口,以 https 方式启动
if __name__ == "__main__":
    import uvicorn
    uvicorn.run(
        "main:app",
        host=SERVER_HOST,
        port=SERVER_PORT,
        log_level="info",
        ssl_certfile="/etc/ssl/local/server.crt",
        ssl_keyfile="/etc/ssl/local/server.key"
    )
```

启动服务：

```bash
sudo $(which python3) main.py
```

## 二、SakuraFrp 启动器安装完成后的服务管理

```bash
# 查看状态
systemctl status natfrp.service
# 停止服务
systemctl stop natfrp.service
# 启动服务
systemctl start natfrp.service
# 查看日志
journalctl -u natfrp.service
```

查看启动器日志：

```bash
sudo journalctl -u natfrp.service -f
```
