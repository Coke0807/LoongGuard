## 1. 环境安装

进入虚拟环境：

```bash
(venv-ui) tjdz@tjdz-pc:~/vss/ParentModel$
```

安装依赖：

```bash
pip install fastapi            # 必需
pip install python-dotenv      # 必需
pip install pyjwt requests passlib[bcrypt]   # 必需
pip install uvicorn websockets # 必需
python-multipart pydantic opencv-python      # 待验证，如缺少，请安装
```

## 2. 本地测试视频流

```bash
# 局域网远程 HLS 流
ffplay -fflags nobuffer -flags low_delay -analyzeduration 1000000 "http://192.168.3.13:8000/stream/live.m3u8"

# 本地 class_stream 流
ffplay -fflags nobuffer -flags low_delay -probesize 32 -analyzeduration 100000 ./class_stream/live.m3u8
```
