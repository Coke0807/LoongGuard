# 家长端与小程序接入（现行方案）

> **状态**：现行方案（2026-08-29 三仓库集成后）。原独立 FastAPI 版
> ParentModel 已合并进主仓库 aiohttp 服务（单端口 8080），旧文档
> 《家长远程功能配置.md》的 `~/vss/ParentModel` 部署方式已废弃。
> 管理后台页面模板位于 `backend/templates/`，静态资源位于 `backend/static/`。

## 1. 架构与鉴权

```
微信小程序 ──POST /api/wx/*  + Authorization: Bearer <JWT>──┐
管理后台   ──/admin 页面 + /api/admin/*，Cookie admin_token─┤
主仓库管理端（Basic Auth）──/api/v1/*、/stream、/ws/alerts──┘
                        全部走同一个 aiohttp 服务（LG_API_PORT，默认 8080）
```

- 家长端自带 JWT 鉴权（PyJWT / HS256），密钥 `LG_PARENT_ADMIN_JWT_SECRET`、
  `LG_PARENT_WX_JWT_SECRET`；**token 有效期 7 天**（2026-08-29 起新签发的
  token 携带 `exp`，过期自动失效）。
- 密钥为空或仍是 `.env.example` 占位值时：开发环境记录 error 日志，
  **生产环境（LG_ENV=production）直接阻断启动**。
- 服务端中间件对 `/api/wx/`、`/api/admin/`、`/admin`、`/static/`、`/uploads/`
  路径豁免主仓库 Basic Auth（家长端自带 JWT），其余路径按
  `LG_API_AUTH_ENABLED` 校验。
- 管理后台 Cookie `admin_token` 已设置 `HttpOnly` + `SameSite=Lax`。

## 2. 管理后台初始化

首次启动（`class_monitor.db` 为空库）时自动建表，并生成：
- 5 条体验公告；
- **随机初始口令**的 `admin` 账号——口令仅在首次创建时输出到日志一次
  （旧版本的固定口令 admin/admin123 已移除）。请立即登录 `/admin/login`
  创建自有账号，并停用该引导账号。

## 3. 小程序端配置

- 后端地址唯一入口：`mini-program/config.js`（开发期 `http://127.0.0.1:8080/api/wx`，
  发布期必须 HTTPS 域名，详见 `mini-program/README.md`）。
- appid：`project.config.json` = `wxd0037d52450fefd0`，须与后端
  `LG_PARENT_WX_APPID/LG_PARENT_WX_APPSECRET` 成对配置（取自分仓库
  `ParentModel/.env` 的完整凭据对）。
- 登录链路：`wx.login` 取 code → `POST /api/wx/login` → 后端调微信
  `jscode2session` 换 openid → 签发 Bearer token。

## 4. 家长绑定关系（后台预录入 → 微信认领）

1. 管理后台 Excel 批量导入（`POST /api/admin/data/import`，模板从
   `/admin/template/data_import` 下载）：学生 + 家长手机号按年级建班入库，
   无微信的家长生成 `import_<md5(手机号)>` 占位 openid。
2. 家长小程序登录后绑定手机号（`POST /api/wx/bind-phone`）：后端把占位
   openid 替换为真实 openid，绑定关系（parent_id）保持不变。

## 7. 远程观看（已闭环，方案 B：ffmpeg HLS + 小程序 video）

```
Pipeline → MJPEG /stream（后端回环）
             │ ffmpeg 切片（media/hls_publisher.py，写 data/hls/）
             ▼
   /stream/live.m3u8 + /stream/live_XXXX.ts          ← aiohttp 服务
             ▲ 带 HMAC 过期 token 鉴权（播放列表自动重写注入 token 到分片 URI）
             │
GET /api/wx/stream/url（JWT + 绑定关系 + 观看开关 + 时段校验）──→ 小程序 <video> 组件
```

- **观看流程**：小程序 monitor 页 → 绑定幼儿列表（`/api/wx/get-student-list`）→
  `GET /api/wx/stream/url?token=&student_id=` → 返回带过期 token 的
  `http://<host>:8080/stream/live.m3u8` → `<video>` 组件直接播放。
- **权限模型**：签发地址前校验绑定关系、`parent_watch_switch` 与允许观看
  时段；TS 分片同样要求 token（无/坏 token 一律 401，已写访问审计）。
- **算力保护**：ffmpeg 仅在有观看者时编码，无观看者超过
  `LG_MEDIA_HLS_IDLE_TIMEOUT_SEC`（默认 180s）自动暂停，有请求自动恢复；
  ffmpeg 崩溃自动退避重启。
- **降级语义**：板端未安装 ffmpeg 或签名密钥未配置时，HLS 端点返回 404
  （MJPEG 本地观看不受影响）；首次拉起编码后播放列表约需 5~15 秒就绪。
- **板端 ffmpeg**：Loongnix 通过 `sudo apt install ffmpeg` 安装（loongarch64
  已被 ffmpeg 上游与 Debian sid 支持；板上具体版本以 `apt policy ffmpeg`
  实测为准）。也可将 `LG_MEDIA_HLS_INPUT` 设为 `/dev/video0` 直接消费
  摄像头，省去回环 MJPEG 一层转发。
- **开发机验证**：Windows 装有 ffmpeg 时同样可端到端跑通（2026-08-29 已用
  ffmpeg 8.1 + 测试视频源实测：播放列表/分片/401 拦截全部符合预期）。
