## 三、语音唤醒方案（已确认：openWakeWord + PocketSphinx）

### 3.1 方案概述

采用**双引擎分离架构**：openWakeWord 专职唤醒，PocketSphinx 专职指令识别。

```
麦克风 → arecord PCM 流 → openWakeWord (唤醒检测)
                              ↓ 命中
                     PocketSphinx (指令识别)
                              ↓
                     CommandHandler (业务分发)
                              ↓
                     TTSBackend (语音播报)
```

**选择理由**：
- openWakeWord 的 ONNX 模型仅 ~200KB，CPU 实时推理无压力
- ONNX Runtime 1.22.2 已有龙芯 `cp313 loongarch64` 官方 wheel
- PocketSphinx `apt install` 即可，零编译
- 唤醒与指令分离，误唤醒低，架构清晰

### 3.5 各文件职责详解

#### `wake_engine.py` — 唤醒引擎

```python
class WakeEngine:
    """openWakeWord 唤醒词检测引擎"""
    
    def __init__(self, model_path: str, threshold: float = 0.5):
        self._model = oww.Model(wakeword_models=[model_path])
        self._threshold = threshold
        self._wake_cooldown = 3.0      # 唤醒冷却秒数
        self._last_wake_time = 0.0
    
    def predict(self, pcm_chunk: bytes) -> bool:
        """检测一帧 PCM 是否包含唤醒词"""
        prediction = self._model.predict(pcm_chunk)
        score = max(prediction.values())
        now = time.time()
        if score > self._threshold and (now - self._last_wake_time > self._wake_cooldown):
            self._last_wake_time = now
            return True
        return False
    
    def reset(self):
        """重置模型状态"""
        self._model.reset()
```

#### `command_handler.py` — 指令处理器

```python
class CommandHandler:
    """PocketSphinx 指令识别 + 业务分发"""
    
    def __init__(self, sphinx_config: dict, callbacks: dict):
        self._decoder = pocketsphinx.Decoder(sphinx_config)
        self._callbacks = callbacks  # 回调函数集合
    
    def recognize_command(self, audio_data: bytes) -> str | None:
        """识别音频中的指令文本"""
        self._decoder.start_utt()
        self._decoder.process_raw(audio_data, False, False)
        self._decoder.end_utt()
        hypothesis = self._decoder.hyp()
        return hypothesis.hypstr if hypothesis else None
    
    async def handle(self, command_text: str) -> bool:
        """执行识别出的指令，返回是否处理成功"""
        if "切换到正常课堂模式" in command_text:
            await self._callbacks["set_mode"]("normal")
            return True
        if "切换到午睡模式" in command_text:
            await self._callbacks["set_mode"]("nap")
            return True
        if "切换到公共区域模式" in command_text:
            await self._callbacks["set_mode"]("public")
            return True
        if "关闭告警" in command_text:
            await self._callbacks["ack_all"]()
            return True
        if "查询温湿度" in command_text or "温湿度" in command_text:
            temp_data = await self._callbacks["get_temp"]()
            return True
        if "开始录制" in command_text:
            await self._callbacks["start_record"]()
            return True
        if "查看日志" in command_text:
            await self._callbacks["get_logs"]()
            return True
        if "关闭识别" in command_text:
            return True  # 由 VoiceService 处理回到待机
        return False
```

#### `tts_backend.py` — TTS 语音播报

```python
class TTSBackend(ABC):
    """TTS 语音播报抽象接口"""
    @abstractmethod
    def speak(self, text: str) -> None: ...

class Pyttsx3TTS(TTSBackend):
    """Windows TTS 后端（pyttsx3）"""
    def speak(self, text: str) -> None:
        engine = pyttsx3.init()
        engine.setProperty("rate", 185)
        engine.setProperty("volume", 0.95)
        # 尝试加载中文语音
        for voice in engine.getProperty('voices'):
            if "zh" in voice.id or "Chinese" in voice.name:
                engine.setProperty('voice', voice.id)
                break
        engine.say(text)
        engine.runAndWait()
        engine.stop()

class EspeakTTS(TTSBackend):
    """Loongnix TTS 后端（espeak）"""
    def speak(self, text: str) -> None:
        subprocess.run(
            ["espeak", "-v", "zh", "-s", "185", "-a", "95", text],
            stdout=subprocess.PIPE, stderr=subprocess.PIPE, check=True
        )

def create_tts_backend(platform: str = "auto") -> TTSBackend:
    """工厂函数：按平台自动选择 TTS 后端"""
    if platform == "auto":
        platform = sys.platform
    if platform == "win32":
        return Pyttsx3TTS()
    return EspeakTTS()
```

#### `voice_service.py` — 语音服务主控

```python
class VoiceService:
    """
    语音服务主控
    
    作为独立线程运行，不阻塞 Pipeline 主循环。
    整合 WakeEngine + CommandHandler + TTSBackend。
    """
    
    def __init__(self, config: VoiceConfig):
        self._config = config
        self._wake_engine = WakeEngine(config.wake_model_path, config.wake_threshold)
        self._command_handler = CommandHandler(config.sphinx_config, config.callbacks)
        self._tts = create_tts_backend()
        self._thread: threading.Thread | None = None
        self._running = False
        self._wake_active = False
        self._wake_timeout = 8.0
    
    async def start(self):
        """启动语音服务（独立线程）"""
        self._running = True
        self._thread = threading.Thread(target=self._run_loop, daemon=True)
        self._thread.start()
        self._tts.speak("AI监护已启动")
    
    async def stop(self):
        """停止语音服务"""
        self._running = False
        if self._thread:
            self._thread.join(timeout=3.0)
        self._tts.speak("AI监护已关闭")
    
    def _run_loop(self):
        """主循环（在线程中运行）"""
        proc = subprocess.Popen(
            ["arecord", "-f", "S16_LE", "-r", "16000", "-c", "1", "-t", "raw", "-"],
            stdout=subprocess.PIPE
        )
        while self._running:
            pcm_data = proc.stdout.read(16000 * 2)  # 0.5秒数据
            if not self._wake_active:
                # 待机状态：检测唤醒词
                if self._wake_engine.predict(pcm_data):
                    self._wake_active = True
                    self._tts.speak("我在")
                    self._handle_command_phase(proc)
            time.sleep(0.05)
        proc.terminate()
    
    def _handle_command_phase(self, proc):
        """唤醒后的指令识别阶段"""
        wake_start = time.time()
        while self._wake_active and self._running:
            # 录制 2-3 秒指令音频
            audio_data = proc.stdout.read(16000 * 2 * 3)  # 3秒
            command = self._command_handler.recognize_command(audio_data)
            if command:
                asyncio.run_coroutine_threadsafe(
                    self._command_handler.handle(command),
                    self._loop
                )
            # 超时自动待机
            if time.time() - wake_start > self._wake_timeout:
                self._wake_active = False
                break
```

### 3.6 语音指令对接真实功能

| 指令 | 对接的真实功能 | 回调函数 | 实现方式 |
|------|---------------|----------|----------|
| 切换到正常课堂模式 | Pipeline 检测模式切换 | `set_mode("normal")` | Pipeline 属性设置 |
| 切换到午睡模式 | Pipeline 检测模式切换 | `set_mode("nap")` | Pipeline 属性设置 |
| 切换到公共区域模式 | Pipeline 检测模式切换 | `set_mode("public")` | Pipeline 属性设置 |
| 关闭告警 | 确认所有未确认告警 | `ack_all()` | 调用 DB 批量确认 |
| 查询温湿度 | RS485 传感器读取 | `get_temp()` | 调用 sensor_thread，无传感器时播报"传感器异常" |
| 开始录制 | 视频录制触发 | `start_record()` | 调用 API 录制端点 |
| 查看日志 | 读取最近日志 | `get_logs()` | TTS 播报最近告警摘要 |
| 关闭识别 | 回到待机状态 | — | VoiceService 内部状态切换 |
| 退出程序 | 安全关闭系统 | `shutdown()` | 调用 Pipeline.stop() |

### 模块 B：家长端管理后台集成（合并到 aiohttp）

**来源**：`ParentModel/website/`
**目标**：合并到 `backend/src/loongguard/api/`
**方式**：将 FastAPI 路由迁移到 aiohttp Handler

**迁移策略**：

家长端管理后台当前使用 FastAPI，主仓库使用 aiohttp。合并方案如下：

#### B.1 API 路由迁移

将 `ParentModel/website/routers/` 中的3组路由迁移到 aiohttp Handler：

| 原 FastAPI 路由 | 迁移后 aiohttp Handler | 功能 |
|-----------------|----------------------|------|
| `wx_api.py` → `POST /api/wx/login` | `parent_routes.py` → 同路径 | 微信登录 |
| `wx_api.py` → `GET /api/wx/student/list` | 同上 | 幼儿列表 |
| `wx_api.py` → `GET /api/wx/stream/url` | 同上 | 视频流权限 |
| `admin_api.py` → 管理员/班级/幼儿/家长/公告/成长记录 CRUD | 同上 | 后台管理全量 API |
| `web_page.py` → HTML 页面路由 | 同上 | Jinja2 模板渲染 |

**实现方式**：
- 创建 `backend/src/loongguard/api/parent_routes.py`，将所有 FastAPI 路由转换为 aiohttp Handler
- 在 `server.py` 的 `AlertAPIServer.start()` 中注册这些新路由
- FastAPI 的依赖注入（`Depends`）改为 aiohttp 中间件或手动调用
- Pydantic 模型验证改为手动 JSON 解析 + 校验

#### B.2 数据层迁移

| 文件 | 处理方式 |
|------|----------|
| `db.py` | 复制到 `backend/src/loongguard/db/parent_db.py`，修改 `DB_PATH` 为 `./data/class_monitor.db` |
| `dependencies.py` | JWT 校验逻辑迁移到 `parent_routes.py` 的中间件中 |
| `utils.py` | 复制到 `backend/src/loongguard/utils/parent_utils.py` |

#### B.3 前端页面迁移

| 文件 | 目标路径 | 处理方式 |
|------|----------|----------|
| `templates/` | `backend/templates/` | 复制，用 `aiohttp_jinja2` 渲染 |
| `static/` | `backend/static/` | 复制，用 `aiohttp` 静态文件挂载 |

#### B.4 路由注册

在 `server.py` 的 `start()` 方法中新增路由：

```python
# 家长端 API 路由（迁移自 FastAPI）
self._app.router.add_post("/api/wx/login", self._handle_wx_login)
self._app.router.add_get("/api/wx/student/list", self._handle_wx_student_list)
self._app.router.add_get("/api/wx/stream/url", self._handle_wx_stream_url)

# 管理后台 API 路由
self._app.router.add_post("/api/admin/login", self._handle_admin_login)
self._app.router.add_get("/api/admin/class/list", self._handle_class_list)
# ... 其余 CRUD 路由

# 管理后台页面路由
self._app.router.add_get("/admin/login", self._handle_admin_page_login)
self._app.router.add_get("/admin/dashboard", self._handle_admin_page_dashboard)
# ... 其余页面路由

# 静态文件
self._app.router.add_static("/static", Path("backend/static"))
```

#### B.5 端口与配置

- 管理后台 API 与主仓库 API 共享同一端口（8080），无需额外端口
- 新增环境变量：


### 模块 C：语音唤醒模块集成

**来源**：`VoiceDetection/long3.py` + `long4.py`（参考实现）
**目标**：`backend/src/loongguard/voice/`
**方式**：基于参考文档重新设计，立即接入 Pipeline

#### C.1 架构设计

```
VoiceService (voice_service.py) — 独立线程运行
├── WakeEngine (wake_engine.py)
│   ├── AudioCapture (arecord 管道 / pyaudio)
│   └── 唤醒词检测器 (openWakeWord ONNX / PocketSphinx KWS / Vosk)
├── CommandHandler (command_handler.py)
│   ├── 模式切换 → Pipeline.set_mode()
│   ├── 关闭告警 → Pipeline.ack_all_alerts()
│   ├── 查询温湿度 → sensor_thread.get_temperature()
│   ├── 开始录制 → api.start_recording()
│   ├── 查看日志 → utils.get_recent_logs()
│   └── 退出程序 → pipeline.stop()
└── TTSBackend (tts_backend.py)
    ├── pyttsx3 (Windows)
    └── espeak (Loongnix)
```

#### C.2 模块文件

| 文件 | 职责 | 重构来源 |
|------|------|----------|
| `__init__.py` | 模块入口，导出 `VoiceService` | 新建 |
| `wake_engine.py` | 音频采集 + 唤醒词检测 + 冷却/超时机制 | long3.py / long4.py 主循环 |
| `command_handler.py` | 语音指令解析 → 调用主仓库真实功能接口 | long3.py `handle_command()` |
| `tts_backend.py` | TTS 语音播报（跨平台） | long3.py / long4.py `speak()` |
| `voice_service.py` | 整合以上组件，提供 start/stop 生命周期 | 新建 |

#### C.3 Pipeline 集成

在 `pipeline.py` 中集成语音服务：

```python
# pipeline.py __init__ 中
from loongguard.voice import VoiceService
self._voice = VoiceService(config.voice)

# pipeline.py start() 中
await self._voice.start()

# pipeline.py stop() 中
await self._voice.stop()
```

**回调注入**：VoiceService 通过回调函数与 Pipeline 协同：
- `on_mode_change(mode)` → Pipeline 切换检测模式
- `on_ack_all()` → Pipeline 确认所有告警
- `on_get_temp()` → 读取传感器数据
- `on_start_record()` → 触发视频录制

#### C.4 语音指令对接真实功能

| 指令 | 对接的真实功能 | 实现方式 |
|------|---------------|----------|
| 切换到正常课堂模式 | Pipeline 检测模式切换 | 回调 `pipeline.set_mode("normal")` |
| 切换到午睡模式 | Pipeline 检测模式切换 | 回调 `pipeline.set_mode("nap")` |
| 切换到公共区域模式 | Pipeline 检测模式切换 | 回调 `pipeline.set_mode("public")` |
| 关闭告警 | 确认所有未确认告警 | 回调 `pipeline.ack_all_alerts()` |
| 查询温湿度 | RS485 传感器读取 | 回调 `sensor_thread.get_data()`，无传感器时播报"传感器异常" |
| 开始录制 | 视频录制触发 | 回调 `api.start_recording()` |
| 查看日志 | 读取最近日志 | 回调 `utils.get_recent_logs()` |
| 退出程序 | 安全关闭系统 | 回调 `pipeline.stop()` |

#### C.5 温湿度数据源

- **优先**：对接 `frontend/ui/sensor_thread.py` 的 RS485 传感器数据
- **降级**：未检测到传感器时，TTS 播报"传感器异常，无法查询温湿度"
- **实现**：VoiceService 通过回调获取传感器数据，传感器线程提供 `get_latest()` 方法

语音唤醒方案（组合A）详细设计

双引擎分离架构：
麦克风 → arecord PCM → openWakeWord (唤醒) → PocketSphinx (指令) → CommandHandler (业务) → TTS (播报)

openWakeWord 唤醒引擎：
- 在 Windows 开发机/Colab 上训练自定义唤醒词模型（"小龙小龙"、"晓珑监护"）
- 导出 .onnx 模型 (~200KB)，放置到 backend/models/wakeword/
- 板端通过 arecord 管道读取 PCM → oww.predict() 实时推理
- ONNX Runtime 1.22.2 有龙芯 cp313 loongarch64 官方 wheel

PocketSphinx 指令识别：
- apt install pocketsphinx python3-pocketsphinx（零编译）
- 下载中文声学模型 + 拼音词典
- 用 JSGF 语法定义固定指令集
- 唤醒后录制 2-3 秒 → 语法约束识别 → 文本匹配

Pipeline 集成：
- VoiceService 作为独立线程运行，不阻塞主循环
- 通过回调函数与 Pipeline 协同（模式切换、告警确认、传感器读取等）
- pipeline.py 的 start() / stop() 中增加语音服务生命周期管理

温湿度降级策略：
- 优先对接 RS485 传感器
- 未检测到传感器时，TTS 播报"传感器异常，无法查询温湿度"
