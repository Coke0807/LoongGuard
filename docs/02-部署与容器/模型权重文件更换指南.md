# 模型权重文件更换指南

## 模型清单

| 模型 | 当前文件路径 | 用途 | 输入尺寸 |
|------|-------------|------|----------|
| YOLO26-Nano | `backend/models/best.onnx` | 危险物品检测（剪刀/美工刀） | 640x640 |
| MoveNet-Lightning | `backend/models/movenet_lightning_int8.onnx` | 俯卧趴睡姿态检测 | 192x192 |
| SCRFD (InsightFace) | `backend/models/buffalo_l/det_10g.onnx` | 人脸检测（睡姿监测） | 动态（默认640x640） |

所有模型必须为 **ONNX 格式**。

---

## 替换方式

### 方式一：环境变量覆盖（推荐）

在项目根目录 `.env` 文件中修改对应变量，无需改动代码：

```bash
# 危险物品检测模型
LG_DETECTION_MODEL_PATH=models/best.onnx

# 姿态估计模型
LG_POSE_MODEL_PATH=models/movenet_lightning_int8.onnx

# 人脸检测模型
LG_FACE_MODEL_PATH=models/buffalo_l/det_10g.onnx
```

路径相对于 `backend/` 目录解析。例如新模型放在 `backend/models/new_model.onnx`，则设为 `models/new_model.onnx`。

---

### 方式二：修改 JSON 配置文件

编辑 `backend/config/default.json`，修改对应字段：

```json
{
    "detection": {
        "model_path": "models/best.onnx"
    },
    "face": {
        "model_path": "models/buffalo_l/det_10g.onnx"
    }
}
```

> **注意**：`pose` 模型路径未暴露在 JSON 配置中，仅支持环境变量或修改代码默认值覆盖。

---

### 方式三：直接替换文件

将新的 ONNX 权重文件重命名为原有文件名，直接覆盖 `backend/models/` 下的对应文件，无需修改任何配置。

---

## 配置优先级

配置加载优先级从高到低：

1. **环境变量**（`LG_DETECTION_MODEL_PATH` 等）- 最高优先级
2. **JSON 配置文件**（`backend/config/default.json`）
3. **代码默认值**（`backend/config/settings.py` 中的 dataclass 默认值）

---

## 替换后注意事项

### 1. 输入尺寸匹配

新模型的输入尺寸需与配置一致，否则推理报错。可通过环境变量调整：

```bash
LG_DETECTION_INPUT_SIZE=640    # 检测模型输入尺寸
```

### 2. 量化标志

若新模型为 INT8 量化版，需设置：

```bash
LG_DETECTION_QUANTIZED=true
```

此标志影响前处理逻辑（量化模型跳过 ImageNet 归一化）。

### 3. 检测类别

若新模型检测不同类别，需同步修改：

```bash
LG_DETECTION_CLASSES='["scissor", "utility_knife"]'
```

或修改 `default.json` 中的 `classes` 数组。

### 4. 人脸模型架构兼容性

当前人脸检测器（`onnx_detector.py`）使用 InsightFace SCRFD 架构的解码逻辑（3级FPN、distance-based bbox解码）。若替换为其他架构的人脸模型，需同步修改后处理代码。

### 5. 推理后端

系统自动检测可用的执行提供程序，优先级：CUDA > OpenCL > CPU。若需指定 OpenCL 设备索引（如龙芯 LG200）：

```bash
LG_DETECTION_OPENCL_DEVICE_ID=0
```

## 语音模型的更换（唤醒词 + PocketSphinx）

语音模块的两套模型不适用上表，替换方式详见
[docs/03-语音与音频/语音唤醒与指令实现.md](../03-语音与音频/语音唤醒与指令实现.md)：

- **唤醒词模型** `models/wakeword/my_wakeword.onnx`：由
  `backend/scripts/train_wakeword.py` 训练产出（仅 Linux/Colab），
  或用 `LG_VOICE_WAKE_MODEL_PATH` 指向新模型。
- **PocketSphinx 中文声学模型** `models/pocketsphinx/zh-cn/`：
  下载 `cmusphinx-zh-cn-5.2.tar.gz` 解压放置（旧文档中
  `zh_broadcastnews_16k_ptm256` 链接已失效）；词典与 JSGF 语法
  随仓库提供，自定义指令时编辑 `commands.jsgf` 并同步
  `command_handler.py` 的别名表。

## 模型文件存放规范

- 主检测模型：`backend/models/`
- InsightFace 套件：`backend/models/buffalo_l/`
- 语音模型：`backend/models/wakeword/`、`backend/models/pocketsphinx/`
- **版本控制说明（2026-08-29 更新）**：核心 ONNX 权重与测试视频已改为
  **Git LFS 入库**（`*.onnx/*.pt/*.tflite/*.mp4`），clone 后必须执行
  `git lfs pull` 还原真实权重（约 580MB），否则工作区只有 ~130 字节指针
  文件、模型加载全部失败；PocketSphinx 声学模型目录与唤醒产物仍由
  `.gitignore` 排除（体积大或需训练产出），按各目录 README 单独放置。

## 验证方法

替换模型后，可通过以下方式验证：

1. 启动服务后查看日志中模型加载信息
2. 访问健康检查端点：
   - 检测模型：`GET /health/detection`
   - 姿态模型：`GET /health/pose`
3. 运行测试：`python -m pytest tests/unit/test_detection.py`
