# RS485 温湿度传感器调试

> 在 Loongnix 平台上调试 USB 转 RS485 温湿度传感器（CH340 芯片）的完整流程。

## 一、调试 USB 口

查看 USB 设备：

```bash
tjdz@tjdz-pc:~$ lsusb
Bus 001 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
Bus 001 Device 002: ID 0bda:b720 Realtek Semiconductor Corp. RTL8723BU 802.11b/g/n WLAN Adapter
Bus 001 Device 003: ID 05e3:0610 Genesys Logic, Inc. Hub
Bus 001 Device 004: ID 046d:c534 Logitech, Inc. Nano Receiver
Bus 001 Device 005: ID 1a86:7523 QinHeng Electronics CH340 serial converter
Bus 002 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub
Bus 003 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
Bus 004 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub
```

> 常会出现 **CH340 / CP2102 / FT232**（USB 转 485 芯片），示例输出：
> `1a86:7523` = CH340 芯片（最常见 USB485 模块）

查看内核日志，插拔传感器实时观察：

```bash
dmesg -w
```

插上传感器瞬间会打印驱动加载日志：

```text
CH340 正常日志示例
usb 1-1: new full-speed USB device number 2 using ohci-platform
usb 1-1: ch341-uart converter now attached to ttyUSB0
```

或使用 grep 过滤：

```bash
tjdz@tjdz-pc:~$ dmesg -w | grep ch341
```

出现 `ttyUSB0 / ttyUSB1` 代表驱动加载成功。

```bash
tjdz@tjdz-pc:~$ ls /dev/ttyUSB*
/dev/ttyUSB0
```

> 有输出 `/dev/ttyUSB0` 说明驱动正常；无输出 = 驱动缺失 / 硬件接触不良。

## 二、确认内核驱动模块是否加载

CH340 芯片：

```bash
tjdz@tjdz-pc:~$ lsmod | grep ch341
ch341                 81920  0
usbserial            180224  1 ch341
```

## 三、权限校验

> Loongnix 普通用户无串口权限会读不到数据。

```bash
tjdz@tjdz-pc:~$ ls -l /dev/ttyUSB0
crw-rw---- 1 root dialout 188, 0  7月/dev/ttyUSB0
```

将当前用户加入 dialout 组（永久生效，重启终端）：

```bash
sudo usermod -aG dialout $USER
```

临时生效（不用重启终端）：

```bash
newgrp dialout
```

## 四、安装 Python 串口库

系统源安装（推荐，无环境污染，串口库优先）：

```bash
sudo apt update
sudo apt install python3-serial
```

虚拟环境中安装 minimalmodbus：

```bash
(venv-ui) tjdz@tjdz-pc:~$ pip install minimalmodbus
Looking in indexes: https://lpypi.loongnix.cn/loongson/pypi, https://pypi.tuna.tsinghua.edu.cn/simple
```

如果失败，考虑下面的方式：

```bash
wget https://raw.githubusercontent.com/pyhys/minimalmodbus/master/minimalmodbus.py
```
