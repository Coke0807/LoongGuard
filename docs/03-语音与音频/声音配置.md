# 声音配置

> 在 Loongnix 上查看音频硬件与 PipeWire 输出/输入设备，并切换默认播放设备。

## 查看音频硬件信息

```bash
echo "===== 物理PCI音频硬件 ====="
lspci | grep -i audio
echo -e "\n===== USB音频设备 ====="
lsusb | grep -i audio
echo -e "\n===== ALSA播放硬件 ====="
aplay -l
echo -e "\n===== ALSA录音硬件 ====="
arecord -l
echo -e "\n===== PipeWire输出设备 ====="
pactl list short sinks
echo -e "\n===== PipeWire输入设备 ====="
pactl list short sources
```

## 查看/切换默认输出设备

查看当前设备：

```bash
tjdz@tjdz-pc:~$ pactl list short sinks
438     alsa_output.pci-0000_00_06.2.hdmi-stereo        PipeWire        s32le 2ch 48000Hz       SUSPENDED
598     alsa_output.usb-CF-IC_HK_MIC_26-0518-1200-0-00.analog-stereo    PipeWire        s16le 2ch 48000Hz       RUNNING
```

**切换声音**（如切换至 USB 声卡）：

```bash
pactl set-default-sink alsa_output.usb-CF-IC_HK_MIC_26-0518-1200-0-00.analog-stereo
```
