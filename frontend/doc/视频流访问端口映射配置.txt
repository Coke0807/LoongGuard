一、类型 1：自签名证书【内网测试、无备案域名】
⚠️重大限制：自签证书微信小程序无法使用！
小程序内核拒绝不受信任 CA，流媒体 HLS 直接加载失败。
仅用于电脑浏览器调试。

sudo apt install openssl
# 创建证书目录
sudo mkdir -p /etc/ssl/local
cd /etc/ssl/local

# 一键生成（IP访问请后续配置SAN扩展，否则浏览器报名称不匹配）
tjdz@tjdz-pc:/etc/ssl/local$ sudo openssl req -x509 -nodes -days 3650 -newkey rsa:2048 \
-keyout server.key \
-out server.crt \
-subj "/C=CN/ST=Tianjin/L=Tianjin/O=Kindergarten/CN=192.168.3.13"

二、SakuraFrp 启动器安装完成, 您可使用下面的命令管理服务:
  - 查看状态    systemctl status natfrp.service
  - 停止服务    systemctl stop natfrp.service
  - 启动服务    systemctl start natfrp.service
  - 查看日志    journalctl -u natfrp.service

查看启动器日志：
sudo journalctl -u natfrp.service -f
