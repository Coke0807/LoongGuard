# "基于LoongArch的幼儿园AI安全卫士" 项目立项书

这是一个面向幼儿园真实场景的智能安全监护系统。项目基于国产全自研 LoongArch 架构平台，利用前沿端侧边缘 AI 技术，旨在攻克幼儿园中高频、隐蔽且关乎幼儿生命安全的痛点隐患（如微小危险品误吞、手持尖锐物、异常俯卧睡姿、环境合规风险等），构建全栈自主可控的校园边缘安全闭环。

---

## 一、 项目背景与痛点分析

### 1.1 问题严峻性
- 近5年全国发生数千起学龄前儿童因微小异物误吞、手持受伤的案例。
- 92.9% 的误吞伤害受害者集中在 0-6 岁幼儿园学龄前儿童。
- 39.3% 因微小危险品导致中重度伤害，其中 25% 需住院手术治疗。

### 1.2 真实安全案例
1. **磁力珠误吞（2025·福州）**：5岁女童吞食38颗磁力珠，肠道吸附成团，面临肠穿孔风险。
2. **纽扣电池灼伤（2024·南京）**：幼儿误含电池10小时，食道被电解液腐蚀穿孔（电池入喉15分钟即开始释放强碱性电解液）。
3. **细小尖锐物扎伤（2021-2024）**：别针、铁丝、碎玻璃等导致数百起幼儿手部、口腔深度扎伤。

### 1.3 行业三大痛点
| 痛点         | 核心问题                                                     | 风险隐患                                 |
| :----------- | :----------------------------------------------------------- | :--------------------------------------- |
| **视觉盲区** | 教师精力有限，传统监控无智能算法，无法实时排查幼儿手部微小异物和午睡高危睡姿。 | 扎伤、误食、窒息、睡姿不当导致猝死。     |
| **时间空档** | 人工巡检为定时制，两次巡检间存在监管真空期，无法应对突发环境风险。 | 地面湿滑摔伤、消防通道堵塞、插座裸露。   |
| **隐私风险** | 市面主流商业 AI 设备高度依赖外网与商业云端传输数据，存在极高隐私泄露隐患。 | 幼儿音视频数据、教室内景画面被黑客窃取。 |

## 二、 产品方案与核心功能

产品定位：不替代老师，而是通过边缘端侧计算，成为老师的 **"超级辅助眼"** 与 **"全能班务管家"**。

### 2.1 核心功能
* **AI 幼儿危险物品手持识别**：精准捕捉磁力珠、纽扣电池、美工刀、剪刀等教室内高危危险品。
* **AI 幼儿高危行为/睡姿检测**：实时捕捉幼儿手持尖锐物，并在午睡时通过骨骼点检测识别高危的“俯卧趴睡（窒息风险）”，及时提醒教师。
* **AI 教室环境合规监测**：7x24小时监测地面水渍、通道堵塞、插座裸露、紫外线灯违规开启等隐患，自动生成合规报告。
* **多模态无触控交互**：支持“小安监护”远场语音唤醒，支持语音消警与日志查询，完全不干扰日常教学秩序。

### 2.2 核心技术壁垒：局域网本地闭环（LAN-based Edge Computing）
系统所有数据采集、AI 边缘推理、加密存储全流程在教室内终端设备本地闭环完成。**坚决不连外网、不上公有云**。推送到教师管理端的仅为结构化告警文本及瞬时风险切片图，从物理和算法源头杜绝幼儿隐私泄露风险。

## 三、 系统架构与技术实现

项目采用**软硬件一体化设计**，各层级全线适配国产信创生态。

### 3.1 硬件基座（LoongArch 架构）
* **主控核心**：**龙芯 2K3000 开发板**（集成 8 个自研龙架构 LA364E 核心）。
* **算力引擎**：内置第二代自研 GPGPU（**LG200**），可提供高达 **8 TOPS 的 INT8 峰值算力**，为端侧实时推理提供强劲动力。
* **物理外设**：高清广角摄像头（视频流输入）、麦克风阵列（远场语音唤醒与定位）、本地蜂鸣器+LED灯组（硬件级分级告警）、多传感器阵列（温湿度、紫外线）。
* **存储与通信**：板载 16GB RAM + 512GB eMMC，支持双路 Wi-Fi 与以太网搭建的局域网通信。

### 3.2 软件架构（分层适配设计）

| 层级                | 核心技术栈与信创适配点                                       | 预期成效与价值                                               |
| :------------------ | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **应用层**          | 动态 ROI 局部高分辨率检测、多级声光告警策略、SM4 国密合规日志存储 | 彻底攻克端侧微小异物漏报问题，确保数据绝对安全。             |
| **视觉算法层**      | **YOLO26-Nano (INT8 量化版)** + **MoveNet-Lightning** 异构双模态算法 | 利用 YOLO26 的 ProgLoss 与 STAL（尺度靶向注意力）技术，大幅提升微小物体识别率，实现 25FPS+ 实时并发推理。 |
| **AI 框架与推理层** | OpenCL 算力框架 + ONNX Runtime / TFLite 龙芯架构定制版       | 原生对接 YOLO26 的 **NMS-Free（免非极大值抑制）端到端设计**，大幅减少边缘 CPU 后处理延迟，完美压榨 LG200 GPU 推理潜能。 |
| **操作系统层**      | **Loongnix_v25_rc1** (针对龙芯架构深度定制的 Linux 系统)     | 系统级低延迟，提供 7x24 小时高稳定无故障运行基座。           |
| **硬件驱动层**      | 基于 V4L2 的摄像头硬解码驱动、通用 GPIO 控制抽象接口（HAL）  | 秒级极速物理告警联动，硬件级闭环。                           |

### 3.3 核心技术难点解决策略（Dynamic ROI）
* **算力与微小物体识别的冲突**：广角监控下，纽扣电池等微小物品像素点极低，且端侧算力无法承受全图高分辨率推理。
* **策略破局**：系统采用**协作式双级检测策略**。
    1. 第一阶段由 YOLO26-Nano 进行全局低分辨率粗筛，并结合画面差分算法锁定“物体变动活跃区域”；
    2. 第二阶段触发**动态 ROI（感兴趣区域）截取**，仅将该局部区域进行高分辨率裁剪，送入龙芯编解码核心放大，再由 YOLO26 进行精准目标分类。用算法策略完美弥补端侧算力与分辨率的矛盾。

### 3.4 “信创+隐私”安全闭环设计
* 依托龙芯 2K3000 芯片内置的 **SM2/3/4 国密硬件加速模块**。
* 视频流数据仅在内存张量（Tensor）中参与即时推理，**断电即失，绝不落盘**。
* 触发警报时生成的预警日志与风险切片，全部调用硬件级 **SM4 加密算法**进行强加密存储。无校长/管理员物理硬件密钥，任何人拆解闪存均无法读取任何幼儿画面。

## 四、 创新亮点

1. **场景创新**：聚焦微小危险物品识别与幼儿午睡俯卧窒息两大蓝海场景，填补传统安防空白。
2. **算法前沿**：率先在国产信创边缘端适配 **YOLO26 最新 NMS-Free 架构**，移除 DFL 模块，在国产边缘芯片上实现极致的运行效率与低算子报错率。
3. **软硬件深度可控**：从底层龙架构（LoongArch）主控、LG200 算力释放到国密加密、上层算法，实现 100% 的全栈自主可控。
4. **极致易用性**：全语音交互，免触控消警，完美融入嘈杂的幼儿园一线教学环境。
